# Ranau Yandex Delivery for WooCommerce

Independent GPL-licensed WooCommerce integration for Yandex pickup points and courier/express quotes. The plugin calculates delivery and saves the confirmed selection to the WooCommerce order; it does not create delivery claims.

Configure credentials and the warehouse under **WooCommerce → Ranau Yandex Delivery**, then add the pickup and/or courier methods to shipping zones.

Source and issues: https://github.com/yudin-s/ranau-yandex-delivery-for-woocommerce

Optional paid support and custom development: https://ranau.uk/
